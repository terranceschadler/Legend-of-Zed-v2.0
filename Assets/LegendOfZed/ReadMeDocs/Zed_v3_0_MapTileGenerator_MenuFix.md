# Zed v3.0 Map Tile Generator Menu Fix

This small patch restores the expected menu path:

`Legend of Zed/Map Integration/Add Runtime Bridge To Scene`

It also keeps the setup-menu alias:

`Legend of Zed/Setup/Map Tile Import/v3.0 Add Runtime Controller Bridge`

## Usage

1. Unzip into the project root so the file lands under `Assets/LegendOfZed/Editor/`.
2. Let Unity finish compiling.
3. Open the map tile generator test scene or any scene containing `ZedLegacyRandomMapGenerator`.
4. Run `Legend of Zed/Map Integration/Add Runtime Bridge To Scene`.
