# v3.10t — Corner Orientation Diagnostics

## Purpose

Do not rewrite corner orientation blindly again.

This adds targeted diagnostics for bad corner buildings.

## Menu

Enable:

`Legend of Zed / Map Integration / v3.10T / Enable Corner Orientation Diagnostics`

Disable:

`Legend of Zed / Map Integration / v3.10T / Disable Corner Orientation Diagnostics`

## Expected Summary Log

`V3.10T CORNER ORIENTATION DIAGNOSTICS complete...`

Look for:

`CornerOrientationDiagnosticLogsPrinted`

## Detailed Log Prefix

`V3.10T CORNER ORIENTATION DIAGNOSTIC`

Send those diagnostic lines for a wrong-facing corner building.
